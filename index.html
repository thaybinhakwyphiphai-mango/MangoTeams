Architecture

Everything is event-driven — there are no polling loops over all players. Session maps are cleaned on PlayerQuitEvent, and chest inventories are released from RAM as soon as the last viewer closes them.

🧩

MangoTeams

Bootstraps storage, manager, listeners and the command executor. On disable: closes every chest GUI, snapshots every team, then drains the IO queue.

🧠

TeamManager

Single source of truth: playerTeam UUID→UUID index, invites (30s), disband confirmation (10s), warmups with primitive block coordinates, rank rules.

💾

StorageManager

One YAML per team. Main thread serializes to a String; a single IO thread writes atomically (tmp + move). Chest = Base64 of Paper's NBT item bytes.

🛡️

ChestDupeListener

Per-player session state, open cooldown, previous-view check, live-inventory identity check on every click/drag, creative-click block, forced close on revoke.

⌨️

TeamCommand

Switch-expression router with tab completion. Every sub-command returns an error string or null on success.

📡

SessionListener

Quit cleanup, warmup cancel on block-change / damage, and a colored team tag in chat through Paper's ChatRenderer.

Configuration config.yml

Operators tune limits, timers, team tags and chat from plugins/MangoTeams/config.yml. Run /team reload (permission mangoteams.admin, console allowed) to apply changes instantly. Values are validated and clamped, so a typo can't break the plugin.

limits.max-homes3Homes per team (0 disables). Lowering never deletes existing homes.
limits.max-warps5Warps per team (0 disables).

Build & install

1 · Create the layout

Place each file at the path shown in its card header (Maven standard layout).

2 · Build
mvn clean package

Requires JDK 21. Output: target/MangoTeams-1.0.0.jar

3 · Install

Drop the jar into plugins/ on a Paper 1.21.11 server and restart. Data appears in plugins/MangoTeams/teams/.

Design notes: teams are loaded eagerly (small YAML each) but chest Inventory objects are created lazily and released when nobody views them. If an item blob ever fails to decode, the raw Base64 is copied to teams/corrupt/ before anything is overwritten. The team Owner cannot leave — they must disband (with confirmation).
